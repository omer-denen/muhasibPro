## 2026-09-02 — Oturum 66 (SelectedFirma null fix — mesaj dispatch race condition — ✅🧪)

### Yapılanlar
- **KÖK SORUN: `SelectedFirma` mesaj dispatch race condition:** `FirmaShellViewModel.OnMessage` callback'i `ContextService.RunAsync` ile `SelectedFirma = FirmaList.SelectedItem` set ediyordu — ama `RunAsync` bir dispatcher dispatch, sıra garanti değil. Kullanıcı firma kartına tıklayıp hemen "Yeni Dönem" basınca `SelectedFirma` henüz null olabiliyordu.
- **Fix 1 — `OnMessage` çift `OnItemSelected` çağrısı kaldırıldı:** `FirmaShellViewModel.OnMessage` içinde `FirmalarVM.OnItemSelected()` çağrılıyordu — ama `FirmalarVM` kendi subscriber'ıyla zaten çağırıyor (çift çağrı). Kaldırıldı, sadece `SelectedFirma = FirmaList.SelectedItem` bırakıldı.
- **Fix 2 — `LoadLastSelection` `SelectedFirma` doğrudan set:** `FirmaList.SelectedItem = lastFirma` sonrası mesaj dispatch'i beklenmeden `SelectedFirma = lastFirma` hemen set. `FirmalarVM.OnItemSelected()` doğrudan çağrısı kaldırıldı (mesaj zaten tetikliyor). `Task.Delay(200)` eklendi — mali dönem yüklemesi için.
- **Fix 3 — `LoadAsync` garanti:** `LoadLastSelection` sonrası `SelectedFirma == null && FirmaList.SelectedItem != null` ise fallback set.

### Kararlar
- **Mesaj dispatch sırası garanti değil:** `MessageService.Send` senkron foreach ile callback'leri çağırır ama callback'ler `async void` + `RunAsync` dispatch → UI thread queue'suna eklenir, sıra çağrı anına bağlı.
- **Çift `OnItemSelected` kaldırıldı:** `FirmalarVM` kendi mesaj subscriber'ı ile `OnItemSelected()` çağırır. `FirmaShellViewModel` orkestratör olarak sadece `SelectedFirma` set eder — çift çağrı yok.

### Doğrulama
- `dotnet build` **0 Hata**
- `SelectedFirma` artık her durumda garanti set: ilk yükleme, son seçim restore, ve kullanıcı tıklaması.
